# Annotation guidelines
Annotate only what the document explicitly supports. Preserve Telugu source text. Every annotation must identify a page and exact character offsets. Use UNKNOWN or AMBIGUOUS rather than guessing.

Labels:

Use independent annotation on a shared sample, measure agreement and adjudicate disagreements with a qualified legal reviewer.
